<p align="center">Application de gestion de l'école Sainte Chantal Soanierana</p>

Il s'agit d'un projet à fort impact dans le domaine de l'enseignement. 
Conçu spécialement pour le Lycée Sainte Chantal Soanierana, le projet répond aux besoins administratifs, pédagogiqueset organisationnels du lycée.

## Technologies et outils utilisés
- PHP v.8.2
- Laravel v.12
- Bootstrap 5
- MySQL

## Installations et configurations
- Avoir PHP v.8.2 ou plus (normalement installé avec Xampp ou Wamp, emplacement : C:\xampp\php\php.exe)
- Ajouter C:\xampp\php dans les variables d'environnement
- Vérification : php -v
- Télécharger Composer via https://getcomposer.org/download/
- Pendant l’installation il demandera l’emplacement de PHP : C:\xampp\php\php.exe
- Vérification : composer -v
- clôner le projet 

!! Si Wampp est le serveur utilisé, il faudra mettre le projet dans C:\xampp\htdocs

## Lancer le projet
- cd répertoire_du_projet
- php artisan serve
